# Final Feature List

Learnova Suite includes:
- Course marketplace
- Student/instructor/admin dashboards
- Course builder
- Modules, lessons, resources, quizzes and assignments
- Live sessions, cohorts and bookings
- Checkout, orders, coupons, bundles and subscriptions
- Certificates, templates and verification
- Instructor earnings, payout methods and withdrawals
- Reviews, questions, discussions and real-time private messages
- Live in-app notification inboxes, admin push campaigns, announcements and email logs
- CMS pages, blog, knowledge base and support tickets
- SEO, redirects, meta overrides, sitemap and robots
- Languages, currencies, payment methods and tax rates
- Import/export, audit logs, jobs, backups and health checks
- API keys, webhooks and integrations
- Affiliate, waitlists, recommendations and saved searches
- Privacy requests, abuse reports and moderation tools
- Feature flags and A/B experiments
- White label and theme customizer
