Learnova Suite Documentation

Learnova Suite is a production-oriented Next.js LMS marketplace for selling online courses, managing instructors, running live classes, issuing certificates, controlling themes, handling sandbox checkout flows, and preparing a production education platform with buyer-friendly setup scripts.

Quick Demo Installation

Use this flow to review the app locally with SQLite and seeded demo data.

npm install
npm run demo:setup
npm run demo:doctor
npm run demo:dev

Open http://localhost:3000.

Optional Smoke Test

Run this in a second terminal while the demo server is running.

npm run demo:smoke

Production Installation

Use PostgreSQL and production environment values for live stores.

cp .env.production.example .env
npm install
npm run production:preflight
npm run prisma:generate:postgres
npm run prisma:push:postgres
npm run build:postgres
npm run start

User Roles

Admin

Controls users, courses, categories, settings, themes, payments, certificates, add-ons, reports, notifications and platform content.

Instructor

Creates courses, uploads content, manages modules, lessons, coupons, live sessions, availability, students and analytics.

Student

Browses courses, purchases through demo checkout, watches lessons, tracks progress, receives certificates and uses messages/notifications.

Security And Content Protection

Security Foundations

  • JWT HTTP-only cookies.
  • Role-based access control.
  • Admin, instructor and student route guards.
  • Origin checks for mutating requests.
  • Rate limiting foundations.
  • Security headers.

Media Protection

  • Paid lesson access checks.
  • Free preview lesson access.
  • Signed media helper foundations.
  • Watermark/logo setting foundations.
  • Recommended private video/object storage.

No LMS can fully prevent screen recording. Use secure providers, signed URLs and clear access rules for practical content protection.

Production Launch Checklist

  • Use PostgreSQL.
  • Set DEMO_MODE=false.
  • Set PAYMENT_SANDBOX_MODE=false.
  • Set ALLOW_LOCAL_UPLOADS=false.
  • Use HTTPS.
  • Set strong unique secrets.
  • Configure SMTP or a transactional email provider.
  • Configure payment provider API keys.
  • Configure payment webhooks.
  • Configure object/video storage.
  • Replace demo courses and media.
  • Replace demo accounts and passwords.
  • Review legal pages.
  • Run npm run production:preflight.
  • Run provider sandbox tests.
  • Run a full checkout test.
