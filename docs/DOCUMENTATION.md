# Learnova Suite Documentation

## 1. Product Analysis
Learnova Suite targets academies, instructors and entrepreneurs who want an LMS marketplace: course sales, instructor onboarding, live classes, commissions, withdrawals, certificates, multilingual content, SEO and dashboards.

## 2. Feature List
Student: account, enroll/buy, progress, videos/files, live sessions, Q&A, reviews, favorites, certificates, invoices and notifications.
Instructor: registration approval, courses, modules, lessons, uploads, pricing, live sessions, students, Q&A, earnings, withdrawals and statistics.
Admin: users, instructor approvals, course approvals, categories, orders, payments, commissions, withdrawals, coupons, reviews, certificates, static pages, blog, settings, languages, currencies, payment methods, SEO and reports.

## 3. User Flows
Student: Home -> Courses -> Details -> Register/Login -> Checkout -> Dashboard -> Learn -> Complete -> Certificate.
Instructor: Register -> Pending Approval -> Create Course -> Submit -> Manage Students/Live/Q&A -> Earnings -> Withdrawal.
Admin: Login -> Overview -> Approve Instructors/Courses -> Manage Catalog/Payments/Settings/Content -> Reports.

## 4. UI System
Modern minimalist dark interface with high-contrast product surfaces: dark background, clear text, focused actions, thin borders, pill buttons, clean typography, mobile-first responsive layouts, RTL-ready `.rtl` support and dark styling enabled by default.

## 5. Included Modules
Authentication, RBAC, public marketplace, course pages, instructor course builder, student learning area, checkout, orders, invoices, commissions, withdrawals, certificates, live sessions, notifications, Q&A, reviews, coupons, CMS pages, blog, settings, languages, currencies, payment method management, reporting, API routes and deployment documentation.

## 6. CodeCanyon Readiness
Includes clean code, env sample, seeders, demo accounts, install docs, API docs, DB docs, customizable colors/logo/settings table and extendable payment gateways.

## 7. Security
bcrypt password hashing, JWT HTTP-only cookies, role checks, Zod validation, Prisma parameterized queries, security headers, origin checks, rate limiting and signed webhook helpers. For production use HTTPS, strong secrets, configured gateway webhooks and private object storage for protected media.

## Commercial Name Suggestion
**Learnova Suite** - A production-oriented LMS marketplace platform for selling online courses and live classes with instructors, commissions and certificates.
