# Marketplace License Notes

Learnova Suite is prepared for marketplace distribution as a web SaaS package with a companion Flutter mobile app. Buyers should follow the marketplace license they purchased.

## Regular License

Use a Regular License for one end product where end users are not charged specifically to access the source package itself. This is usually suitable for a buyer running one learning marketplace for their own brand.

## Extended License

Use an Extended License when the final end product charges end users for access in a way that requires the broader commercial rights described by the marketplace terms.

## Included Source

The package includes:

- Next.js web SaaS source code.
- Flutter mobile app source code.
- Documentation, setup scripts, and buyer preflight checks.
- Mock/local evaluation data for installation testing.

## Third-Party Assets

Preview assets, icons, fonts, and package dependencies remain subject to their own licenses. Review `docs/ASSET_LICENSES.md` and `docs/THIRD_PARTY_NOTICES.md` before replacing or redistributing assets.

## Support Scope

Included support covers installation guidance, configuration clarification, bug reports related to the included source, and documentation questions. It does not include custom feature development, server administration, payment-provider business approval, or creating third-party service accounts.
