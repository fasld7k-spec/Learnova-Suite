# CodeCanyon Seller Page Copy

## Title
Learnova Suite - Live Learning Marketplace SaaS With Cohorts

## Short Description
Launch a live learning marketplace with redesigned student/instructor dashboards, admin controls, AI assistant, messages, notifications, live sessions, subscriptions, coupons, certificates, invoices, CMS, blog, SEO and seven distinct homepage themes.

## Key Features
- Student, Instructor and Admin dashboards
- Redesigned student dashboard with progress, calendar, courses, upcoming work and achievements
- Redesigned instructor dashboard with revenue, students, calendar, course management, tasks and notifications
- Admin-configurable AI assistant with OpenAI, DeepSeek, OpenRouter, demo fallback or custom OpenAI-compatible endpoints
- Advanced messages and priority notifications with admin operations
- Seven distinct homepage themes with desktop/mobile visual QA
- Course marketplace with modules and lessons
- Quiz builder and learning progress
- Live class scheduling
- Manual payment workflow plus Stripe, PayPal, Razorpay, Paystack, Flutterwave, Mollie, Paymob, Tap Payments, Midtrans, Xendit, and SSLCommerz checkout foundations
- Payment gateway manager for hosted checkout URLs and custom provider adapters
- Coupons, subscriptions and course bundles
- Certificates with verification codes
- Instructor earnings and withdrawals
- CMS pages, blog, sliders and SEO settings
- Admin-selectable single active language with RTL/LTR-ready UI
- Demo data, documentation and installation guide
- Protected lesson media delivery with signed access checks
- Public documentation index and asset/license notes for buyers
- Install checker, release checklist and smoke-test script for reviewer QA

## Tech Stack
Next.js 16, TypeScript, Tailwind CSS, Prisma, SQLite demo mode, PostgreSQL production schema.

## Requirements
- Node.js 20+
- npm 10+
- PostgreSQL 14+ for production deployments

## Payment Notice
Demo mode uses sandbox/mock checkout screens so buyers can test without external provider accounts. Live stores must configure real provider credentials, webhook secrets, production URLs, and provider sandbox QA before accepting payments.

## Asset Notice
Included demo media is bundled for review and buyer customization. Replace demo course media, screenshots, and brand assets with your own licensed production assets before launching a live marketplace.
