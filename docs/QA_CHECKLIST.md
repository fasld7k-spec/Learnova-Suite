# QA Checklist

## Public Website
- Home page loads.
- Courses list and filters work.
- Course detail loads and checkout form appears.
- Blog, pages, instructors, categories, bundles and cohorts load.

## Auth
- Student registration.
- Instructor registration and pending approval.
- Admin login.
- Logout.

## Admin
- Approve instructor.
- Publish course.
- Create category/coupon/subscription plan/bundle.
- Mark order paid.
- Review reports/export/import/audit logs.

## Instructor
- Create course.
- Add modules/lessons/resources/quizzes/assignments.
- Create live session/cohort.
- Answer questions and manage bookings.

## Student
- Buy/enroll course.
- Complete lessons.
- Take quiz.
- View certificate.
- Submit assignment.
- Use favorites/collections/goals/badges.

## Production
- Run build.
- Run the documented schema sync command for the target database.
- Configure environment variables.
- Test email/payment/upload providers.
